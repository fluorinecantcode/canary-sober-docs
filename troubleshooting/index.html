Troubleshooting

Use may violate the Roblox Terms of Service. Bans are possible. No undetectable claim is made.

Logs: $XDG_DATA_HOME/canary/session-*.log, fallback ~/.local/share/canary/session-*.log. Last 10 kept by mtime at logger init. Prefixes [+] info / [!] warn / [x] error.

Exit codes​

ExitCauseFix
2Compositor missing: compositor required (enable picom/kwin/mutter compositing); or no X display (xdpyinfo failed)enable compositing; check DISPLAY with xdpyinfo. When canary runs as root it also prints which half failed; a root overlay needs X access, which this class of server only grants per user — canary grants and revokes it with xhost +SI:localuser:root, so xhost must be installed (xorg-xhost on Arch, x11-xserver-utils on Debian/Ubuntu)
3native Wayland not supported in MVP (use XWayland)run under XWayland, not native Wayland
4Sober not found after 60s (500 ms retry, 120 attempts)start Sober first, confirm sober process + libroblox.so maps
5EPERM persists, or the sudo password was refused: sudo refused that password; canary needs root to read Sober (flatpak sandbox, yama ptrace_scope)a bare canary asks for the sudo password and re-runs as root, and exits 5 with no unprivileged fallback when that password is refused; check it with plain sudo -v first, or set CANARY_NO_ELEVATE=1 to skip the prompt and fix it by hand: echo 0 | sudo tee /proc/sys/kernel/yama/ptrace_scope OR sudo setcap cap_sys_ptrace <realpath>; run cheat as the same user as Sober (loginctl show-user)
6run on host, not inside Flatpak (/.flatpak-info exists)run on the host, not inside Flatpak

FUSE (AppImage run machine)​

libfuse2 on Ubuntu 22.04; libfuse2t64 on newer distros. FUSE is only needed where the AppImage runs, not for building.

Display check​

xdpyinfo   # exit 0 required for --x11; else exit 2
