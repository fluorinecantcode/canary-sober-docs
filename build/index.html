Build

Builder: Ubuntu 22.04 + gcc-12 (C++20 atomic<shared_ptr> floor). GLFW is vendored (third_party/glfw, static) — never install a system glfw package. xdpyinfo (X11 display check) and XRandR headers are builder deps. Yama is a runtime setting, not a package. FUSE is only needed on the machine that runs the P4 AppImage, not for building.

Ubuntu 22.04​

sudo apt-get update
sudo DEBIAN_FRONTEND=noninteractive apt-get install -y --no-install-recommends \
  ca-certificates git cmake make g++-12 gcc-12 python3 pkg-config \
  libx11-dev libxext-dev libxrandr-dev libxinerama-dev libxcursor-dev libxi-dev \
  x11-utils
CC=gcc-12 CXX=g++-12 cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j"$(nproc)"
ctest --test-dir build -LE e2e --output-on-failure

FUSE note (run machine, 22.04): libfuse2. Newer distros use libfuse2t64.

Fedora 42​

sudo dnf install -y git cmake make gcc-c++ python3 pkgconf \
  libX11-devel libXext-devel libXrandr-devel libXinerama-devel libXcursor-devel libXi-devel \
  xdpyinfo
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j"$(nproc)"
ctest --test-dir build -LE e2e --output-on-failure

Arch​

sudo pacman -Syu --needed base-devel cmake git python pkgconf \
  libx11 libxext libxrandr libxinerama libxcursor libxi xorg-xdpyinfo
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j"$(nproc)"
ctest --test-dir build -LE e2e --output-on-failure

Sanitizers (Ubuntu, Debug)​

CC=gcc-12 CXX=g++-12 cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug -DENABLE_SANITIZERS=ON
cmake --build build -j"$(nproc)"
ASAN_OPTIONS=halt_on_error=1 ctest --test-dir build -LE e2e --output-on-failure

Offline configure check​

BUILD_TESTING=OFF skips test deps entirely (no game, no network beyond the vendored sources):

cmake -S . -B build -DENABLE_E2E=OFF -DBUILD_TESTING=OFF
cmake --build build
