Config

Path: $XDG_CONFIG_HOME/canary/config.json, fallback ~/.config/canary/config.json. Schema v1 (no migration; P5 handles v1 → v2).

  • Unknown fields are ignored but preserved on save.
  • Missing fields are filled with defaults.

Overlay behaviour​

  • Follows the Sober window wherever it moves (any monitor). Manual monitor select is only the fallback rect when the tracker fails.
  • HiDPI: scale = fbSize / winSize, recomputed on every tracker update; all W2S + draw in framebuffer pixels.
